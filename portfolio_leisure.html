Project Description

Leisure.com is a Flutter travel booking application focused on hotel discovery and trip planning. The app helps users search destinations, compare hotel deals, save preferred stays, and continue through a smoother checkout flow.

For this organization client project, the mobile experience was built with Flutter so the same product foundation could support iPhone, iPad, Android, and Apple silicon Mac compatibility from one codebase.

  • Hotel search, listing, filtering, and sorting flows

  • Wishlist support for saving hotels during planning

  • Checkout, payments, trip management, FAQ, and contact flows

  • Responsive Flutter UI for mobile and tablet form factors

  • Performance-focused updates for faster launch and browsing
